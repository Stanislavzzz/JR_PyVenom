### Узнать текущего пользователя

```bash
whoami
```

### Показать текущую директорию

```bash
pwd
```

### Показать содержимое директории

```bash
ls
```

### Показать содержимое с подробной информацией

```bash
ls -l
```

### Показать все файлы, включая скрытые

```bash
ls --all
```

### Перейти в системную директорию `/home`

```bash
cd /home/
```

### Перейти в папку `home` внутри текущей директории

```bash
cd ./home
```

### Перейти на один уровень выше

```bash
cd ..
```

### Перейти в домашнюю директорию пользователя

```bash
cd ~
```

### Очистить терминал

```bash
clear
```

### Автодополнение команды или пути

```text
Tab
```

### Остановить выполняющуюся команду

```text
Ctrl + C
```

### Завершить ввод или выйти из терминала

```text
Ctrl + D
```

### Создать директорию `/work`

```bash
mkdir /work
```

### Создать пустой файл `README.md`

```bash
touch README.md
```
