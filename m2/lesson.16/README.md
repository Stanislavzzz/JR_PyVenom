### Изменить права доступа

```bash

```

### Добавить владельцу право на выполнение файла

```bash
chmod u+x main.py
```

### Обозначения пользователей в `chmod`

```text
u — пользователь, владелец файла
g — группа
o — остальные пользователи
a — все пользователи
```

### Операции изменения прав

```text
+ — добавить права
- — убрать права
= — установить точные права
```

Пример установки точных прав владельцу:

```bash
chmod u=rw main.py
```

### Обозначения прав доступа

```text
r — чтение
w — запись
x — выполнение
```

### Убрать у владельца право чтения директории

```bash
chmod u-r user/
```

### Изменить владельца файла или директории

```bash

```
